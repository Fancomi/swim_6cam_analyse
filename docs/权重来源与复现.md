# 权重来源与复现说明

> 原则：**开发机（Linux）负责训练，Windows 只做工程**。
> `weights/` 下的 4 个权重都是**训练完成的成品**（不入库，由外部交付），
> Windows 无需重训，直接 `scripts/build.bat`（内部调 `cpp/tools/export_onnx.py`）→ TRT 即可。

## 权重总览

| 文件 | 用途 | 来源 | 本地可复现 |
|---|---|---|---|
| `weights/yolo_swim_detect.pt` | 泳者检测（Plan A/C + C++ detect） | dingyuhang 007_Code 训练 | ❌ 训练产物已清理 |
| `weights/rtmpose_m_swim.pth` | 原相机 RTMPose-m（Plan A） | dingyuhang 007_Code 训练 | ❌ 训练产物已清理 |
| `weights/plans/planB_yolo26x_pose_canvas.pt` | 画布 YOLO-Pose 一体（Plan B） | 本机 `.exp` 训练 | ✅ md5 已验证 |
| `weights/plans/planC_rtmpose_m_canvas.pth` | 画布 RTMPose-m（Plan C + C++ pose） | 本机 `.exp` 训练 | ✅ md5 已验证 |

## 1) yolo_swim_detect.pt（113M，检测器）

- **架构**：yolo26x（end2end，NMS 内置），单类 person，imgsz=640
- **训练**：dingyuhang 007_Code → `output/yolo_detect_finetune/train-3`
  - 基座 `yolo26x.pt`，imgsz=640，100 epochs，batch 16，数据 `output/yolo_detect_dataset/data.yaml`
  - 该训练目录已不在本机（dingyuhang 交接目录清理），**无法本地重训复现**
- **替代**：如需重训，用 `.exp/train_yolo.py`（ultralytics）从头训，数据格式见 `.exp/yolo2coco.py` / `.exp/build_canvas_dataset.py`

## 2) rtmpose_m_swim.pth（105M，原相机 RTMPose）

- **架构**：RTMPose-m，输入 256×192
- **训练**：dingyuhang 007_Code → `src/RTMPose/work_dirs/rtmpose-m_swim`，epoch 95
- 训练产物不在本机，**无法本地复现**

## 3) planB_yolo26x_pose_canvas.pt（121M，画布 YOLO-Pose 一体）

- **来源**：`.exp/yolo/ts_1920/weights/best.pt`（md5 `3ff4eb82...` 完全一致）
- **训练命令**（launch3.sh 第 3 批，GPU0）：
  ```bash
  .venv/bin/python .exp/train_yolo.py --imgsz 1920 --name ts_1920 --epochs 40 --batch 8 --rect --workers 6
  ```
- **基座**：`.exp/yolo26x-pose.pt`；**数据**：`.exp/data/canvas_pseudo_ts/data.yaml`（伪标签，由 `.exp/gen_pseudo_labels.py` 生成）
- **复现**：`.exp` 目录完整保留（脚本+配置+数据集+训练产物），可重跑

## 4) planC_rtmpose_m_canvas.pth（107M，画布 RTMPose）

- **来源**：`.exp/work_dirs/rtm_canvas_192x256/best_coco_AP_epoch_40.pth`（md5 `c8e7a76c...` 完全一致）
- **训练命令**（launch3.sh 第 3 批，GPU3）：
  ```bash
  .venv/bin/python .exp/train_rtmpose.py .exp/configs/rtm_canvas_192x256.py --epochs 40 --batch 64
  ```
- **数据**：`.exp/data/canvas_coco/`（COCO 格式关键点标注）
- **复现**：`.exp` 目录完整保留，可重跑

## 中间产物 pipeline（训练 → 部署）

```
训练基座（.exp/*.pt / rtmpose-m_coco_pretrain.pth）
  → 开发机训练（.exp/train_yolo.py / train_rtmpose.py）
  → 训练产物（.exp/work_dirs / .exp/yolo/*/weights/best.pt）
  → 成品权重（weights/*.pt|*.pth，外部交付，不入库）
  → 导出 ONNX（cpp/tools/export_onnx.py，detect 必须 imgsz=640；scripts/build.bat 会自动调）
  → TRT engine（首次运行自动构建，与 GPU + TRT 版本绑定，现场生成）
  → C++ 推理（cpp/build/Release/swim_analyse.exe）
```

## 数据集生成链路（.exp 内部）

```
原始六路相机视频（data/20260629/cam*.mp4）
  → build_canvas_dataset.py（拼接画布 + 标注）
  → gen_pseudo_labels.py（YOLO-Pose 伪标签）
  → canvas_pseudo_ts / canvas_coco（训练数据）
  → train_yolo.py / train_rtmpose.py
```

> 注意：`.exp/` 是实验目录（89G，含数据），未随权重分发。如需重训需从开发机拷贝。
> `data/20260629/`（六路原相机视频，Plan A 与数据集生成都要它）同样未分发。
